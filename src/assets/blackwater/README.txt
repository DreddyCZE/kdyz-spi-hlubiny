BLACKWATER – BALÍČEK ILUSTRACÍ (pracovní výřezy)

Tyto PNG jsou vyříznuté z nově vytvořeného grafického návrhu. Nejde o původní samostatně generované čisté ilustrace; některé mohou obsahovat dekorativní rámečky a mají nižší rozlišení.

Doporučené přiřazení:
myth_first_strike.png -> karta mýtu První úder
location_harbor.png -> Přístav
location_lighthouse.png -> Maják
investigator_detective.png -> Detektiv
monster_drowned_sailor.png -> Utopený námořník
result_evidence.png -> Výsledková karta / nalezená stopa

Při uploadu do GitHub repozitáře zachovej názvy a vlož obrázky do src/assets/blackwater/. Následně bude třeba upravit odkazy ve src/ui/blackwater.js a související mapování ilustrací; samotný upload nestačí.

Soubor full_design_reference.png je původní kompletní návrh pro porovnání.
